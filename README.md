## Projects

### 🎮 Pokédex Claude Skill + Plugin
A custom Claude Skill and Plugin grounded in structured JSON reference files covering all **1,000+ Pokémon across Generations 1-9**. Built to learn Anthropic's Skills and Plugins systems and explore what those tools are actually capable of.

Under the hood:
- `pokemon_compact.json` — type, origin, color, height, weight, gender ratio, Pokédex descriptions
- `pokemon_extra_data.json` — base stats, abilities (including hidden), egg groups, catch rates, legendary/mythical flags
- `pokemon_moves.json` — 765 moves with type, category, power, accuracy, PP, and effect descriptions
- `type_chart.json` — full effectiveness chart across all 18 types
- A Python search script for fast queries without loading full datasets into memory

Ask it something like *"which Gen 4 Dragon types have a BST over 600?"* and it actually runs the query.
